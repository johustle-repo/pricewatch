PriceWatch Public Board Algorithm Explanation

Overview

The public price board shows the latest agricultural commodity prices in a clean rotating display. Instead of showing every product at once, the system shows 12 agricultural products per page so the board stays readable on a large screen.


How the Board Chooses What to Show

1. The system loads all available agricultural market price records.

2. The board is set to show 12 products at a time.

3. The system counts how many pages are needed.

   Example:
   If there are 14 agricultural products and the board shows 12 at a time:

   14 products / 12 products per page = 2 pages

   Page 1 shows the first 12 products.
   Page 2 shows the remaining 2 products.

4. Every 30 seconds, the board automatically moves to the next page.

   Example:
   Page 1 -> Page 2 -> Page 1 -> Page 2

   This loop continues while the public board is open.


How Products Are Arranged on the Screen

The visible products are divided into columns.

For 12 products:

Column 1 shows products 1 to 4.
Column 2 shows products 5 to 8.
Column 3 shows products 9 to 12.

This creates a balanced 3-column layout with 4 rows.


How the Board Fits the Screen

The board calculates how much screen height is available after the header and footer are shown.

Then it divides that available height by the number of product rows.

This lets each product card adjust its height automatically, so the board can fill the full screen without leaving awkward empty space or causing overflow.


Why This Algorithm Is Useful

The board stays readable because it only shows 12 products at a time.
The display rotates automatically, so users can eventually see all products.
The layout adjusts to the screen size.
The footer remains visible.
The board avoids overflow errors while still using the full display area.


Presenter Script

"The public board uses pagination. It does not show all products at once because that would make the screen crowded. Instead, it displays 12 agricultural products per page. If there are 14 products, the system creates 2 pages. The first page shows 12 products, and the second page shows the remaining 2.

Every 30 seconds, the board automatically moves to the next page. After the last page, it returns to the first page. This keeps the display moving without requiring the user to click anything.

For the layout, the 12 products are divided into 3 columns, with 4 products in each column. The system also calculates the available screen height and adjusts the product card height so the board fills the screen properly without overflow."
